# 🌟 Перевод квестов на русский язык: Dungeon Heroes (RPG Series) 2.7.5

⚔️ **Explore, Triumph, Loot — Together!**

Русский перевод квестовой книги для **Dungeon Heroes 2.7.5 / Minecraft 1.21.1 (Fabric)** на основе перевода 2.4.2.

---

## 📥 Установка перевода

1. Установите или обновите сборку до [Dungeon Heroes 2.7.5](https://www.curseforge.com/minecraft/modpacks/dungeon-heroes/files/9046574).
2. Скачайте [архив перевода для 2.7.5](<Dungeon Heroes (RPG Series) 2.7.5.zip>).
3. Распакуйте папку `config` из архива в папку игры выбранного профиля сборки — туда, где находятся `mods` и `config`. При запросе замените `ru_ru.snbt`.
4. В настройках Minecraft выберите **Русский (Россия)** и перезапустите игру.

После установки файл должен находиться по пути `config/ftbquests/quests/lang/ru_ru.snbt` внутри папки игры.

Архив содержит только русский языковой файл. Он сохраняет оригинальный английский текст, задания, награды и команды сборки 2.7.5. Переводы интерфейсов и предметов отдельных модов в этот пакет не входят.

Если вы уже установили старый русификатор 2.4.2 поверх сборки 2.7.5, сначала восстановите папку `config/ftbquests/quests` из чистой сборки 2.7.5: старый архив заменял файл заданий и английский языковой файл. Затем установите новый перевод.
